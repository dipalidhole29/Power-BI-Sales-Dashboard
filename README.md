# Power BI Sales Dashboard Project

## 📌 Project Overview
This project focuses on analyzing sales data and creating an interactive dashboard using Microsoft Power BI. The dashboard helps users understand sales performance, identify trends, and make data-driven decisions.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify top-performing products and categories.
- Track sales trends and key performance indicators (KPIs).
- Present insights through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

## 📊 Dashboard Features
- Interactive charts and graphs
- Sales performance KPIs
- Product and category analysis
- Trend analysis
- Interactive filters and slicers

## 📁 Project Files
- `PowerBI Project - Mobile Sales Dashboard.pbix` — Power BI project file.
- `Dashboard.png` — Dashboard preview.
